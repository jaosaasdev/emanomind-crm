# EMANOMIND CRM

Frontend do sistema de gestão da agência EMANOMIND (Branding & Automation).

## Como usar

Abra o arquivo `index.html` no navegador.

## Telas

- Visão Geral
- Pipeline (Kanban com drag-and-drop)
- Projetos
- Processos
- Leads
- Propostas
- Contratos
- Clientes

Paleta dark glass + accent `#f0a07a`.
